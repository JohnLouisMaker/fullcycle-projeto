# Registro de uso de IA

## Escopo do registro

Este documento registra a assistência de IA usada para preparar os entregáveis de documentação deste projeto. O histórico de prompts de etapas anteriores do curso não foi fornecido junto ao repositório; por isso, não são atribuídos nem reconstruídos prompts que não estejam disponíveis.

## Uso registrado

| Atividade                    | Prompt/solicitação registrada                                                                                                                                                                          | Uso da IA                                                                                                                                                              | Verificação humana                                                                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Documentação dos entregáveis | Solicitação para completar os entregáveis do Projeto B com uma especificação OpenAPI 3.0 das rotas, um relatório/script de smoke test k6 com medição de p95 e o registro dos prompts de IA utilizados. | Inspecionar a implementação existente e redigir `docs/openapi.yaml`, `docs/desempenho.md` e este registro, sem inventar medições de desempenho nem prompts anteriores. | Conferir rotas, parâmetros, modelos, códigos de resposta e validações contra o código da API e testes; executar/validar o teste k6 e preencher os resultados observados quando possível. |
