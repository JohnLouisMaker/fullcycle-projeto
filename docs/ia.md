# Registro de uso de IA

## Escopo do registro

Este documento registra a assistência de IA usada para preparar os entregáveis de documentação deste projeto. O histórico de prompts de etapas anteriores do curso não foi fornecido junto ao repositório; por isso, não são atribuídos nem reconstruídos prompts que não estejam disponíveis.
