## Projeto B

Base do projeto do curso Full Cycle: construção incremental de uma API REST para gerenciamento de um acervo de livros.

## Escopo previsto

A API será desenvolvida em Python com FastAPI e terá como domínio principal o cadastro e a listagem de livros. A implementação será organizada em camadas de Controller, Service e Repository em memória, com logs estruturados, métricas Prometheus, testes automatizados e execução em contêineres.

> Esta etapa inicial contém somente a documentação-base e arquivos para evitar o versionamento de segredos e artefatos locais. A aplicação e os demais componentes serão adicionados nos próximos commits.
